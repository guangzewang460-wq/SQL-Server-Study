# 公共配置页面完整案例教程

## 案例：图书管理＋图书标签上下选

这个案例只保留三个主要业务字段，方便你把重点放在公共页面的完整开发流程上：

```
图书编号
图书名称
图书价格
```

需要完成的功能：

```
图书主页面
├─ 查询
├─ 查看明细
├─ 新增
├─ 修改
├─ 删除
├─ 查看操作记录
└─ 右键“图书标签管理”
   └─ 打开上下选页面
      ├─ 单选
      ├─ 单删
      ├─ 全选
      ├─ 全删
      └─ 保存
```

本案例使用：

```
业务数据库：TEST
公共配置库：PUBLIC_CS
```

------

# 一、先理解完整调用关系

## 1. 主页面调用关系

```
图书管理页面
    ↓
base_ggmkmain定义页面
    ↓
base_ggmkdetail定义查询、新增、修改、删除控件
    ↓
base_ggmkright定义右键菜单
    ↓
t_ggmk_routes查找业务存储过程
    ↓
执行查询、明细或操作存储过程
```

## 2. 上下选调用关系

```
选中一条图书
    ↓
右键“图书标签管理”
    ↓
base_ggmkright.lx=6
    ↓
打开form_common_comment
    ↓
将当前行“图书编号”传入@args1
    ↓
t_ggmk_routes查找上下选查询、操作过程
    ↓
上方显示未选标签
下方显示已选标签
```

# 三、参数分工

先记住下面这张表。

| 参数             | 作用                           |
| ---------------- | ------------------------------ |
| `@edit1～@editN` | 查询、新增、修改等普通表单数据 |
| `@pkey1`         | 当前选中行主键                 |
| `@clyj1`         | 删除原因、处理意见             |
| `@args1`         | 从主页面传到另一个页面的数据   |
| `@action`        | 新增、修改、删除的业务动作     |
| `@fs`            | 上下选动作                     |
| `@czydm`         | 当前操作人工号                 |
| `@czyxm`         | 当前操作人姓名                 |
| `@flag_sm`       | 返回操作提示                   |

本案例统一约定：

## 主页面查询

```
@edit1 = 图书编号
@edit2 = 图书名称
@edit3 = 记录状态
```

## 新增、修改页面

```
@edit1 = 图书编号
@edit2 = 图书名称
@edit3 = 图书价格
```

## 删除

```
@pkey1 = 图书编号
@clyj1 = 删除原因
```

## 上下选

```
@args1 = 主页面右键传入的图书编号
@pkey1 = 当前标签编号
@edit2 = 标签查询条件
```

| ------ | ------ |

| `qx`   | 全选   |

# 七、主页面查询存储过程

主页面查询使用：

```
@edit1 = 图书编号
@edit2 = 图书名称
@edit3 = 记录状态
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_demo_book_query
    @args1 NVARCHAR(500) = '',

    @edit1 NVARCHAR(500) = '',
    @edit2 NVARCHAR(500) = '',
    @edit3 NVARCHAR(500) = '',
    @edit4 NVARCHAR(500) = '',
    @edit5 NVARCHAR(500) = '',

    @pkey1 NVARCHAR(500) = '',

    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',

    @flag_sm NVARCHAR(1000) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;

    SET @flag_sm = N'';

    SELECT
        a.book_code AS [图书编号],
        a.book_name AS [图书名称],
        a.book_price AS [图书价格],

        ISNULL
        (
            (
                SELECT
                    STRING_AGG
                    (
                        CONVERT(NVARCHAR(MAX), t.tag_name),
                        N'、'
                    )
                    WITHIN GROUP
                    (
                        ORDER BY t.sort_no, t.tag_code
                    )
                FROM dbo.t_demo_book_tag_rel r

                INNER JOIN dbo.t_demo_tag t
                    ON t.tag_code = r.tag_code

                WHERE r.book_code = a.book_code
                  AND t.flag_enable = 1
                  AND t.flag_zf = 0
            ),
            N''
        ) AS [图书标签],

        CASE a.flag_zf
            WHEN 1 THEN N'已删除'
            ELSE N'正常'
        END AS [记录状态],

        a.bz_zf AS [删除原因],
        a.czyxm_dj AS [最后操作人],

        CONVERT(VARCHAR(19), a.time_dj, 120)
            AS [最后操作时间]

    FROM dbo.t_demo_book a WITH(NOLOCK)

    WHERE
        (
            ISNULL(@edit1, '') = ''
            OR a.book_code LIKE '%' + @edit1 + '%'
        )

        AND
        (
            ISNULL(@edit2, '') = ''
            OR a.book_name LIKE N'%' + @edit2 + N'%'
        )

        AND
        (
            (
                ISNULL(@edit3, '') IN ('', N'正常')
                AND a.flag_zf = 0
            )
            OR
            (
                @edit3 = N'已删除'
                AND a.flag_zf = 1
            )
            OR
            (
                @edit3 = N'全部'
            )
        )

    ORDER BY a.book_code;
END
GO
```

## 为什么标签不能直接普通关联

错误思路：

```
FROM t_demo_book a
JOIN t_demo_book_tag_rel r
    ON r.book_code = a.book_code
```

一本图书有三个标签时，图书主页面就会出现三行。

因此这里使用：

```
STRING_AGG
```

把多个标签合并成一列：

```
计算机、数据库、入门教材
```

# 八、明细查询存储过程

明细查询用于：

```
查看图书明细
修改窗口打开时回填原数据
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_demo_book_detail
    @args1 NVARCHAR(500) = '',

    @edit1 NVARCHAR(500) = '',

    @pkey1 NVARCHAR(500) = '',

    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',

    @flag_sm NVARCHAR(1000) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @book_code VARCHAR(20);

    SET @flag_sm = N'';

    SET @book_code =
        COALESCE
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@pkey1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    IF ISNULL(@book_code, '') = ''
    BEGIN
        SET @flag_sm = N'没有获取到图书编号。';
        RETURN;
    END;

    SELECT
        a.book_code AS [图书编号],
        a.book_name AS [图书名称],
        CONVERT(VARCHAR(50), a.book_price) AS [图书价格]

    FROM dbo.t_demo_book a WITH(NOLOCK)

    WHERE a.book_code = @book_code;

    IF @@ROWCOUNT = 0
    BEGIN
        SET @flag_sm =
            N'没有找到图书编号：'
            + @book_code;
    END;
END
GO
```

返回列顺序：

```
第1列 图书编号
第2列 图书名称
第3列 图书价格
```

修改控件也必须按照同样顺序配置。

# 九、新增、修改、删除存储过程

本案例统一使用：

```
@action='add'     新增
@action='update'  修改
@action='delete'  删除
```

如果你系统实际把动作放在 `@lx` 中，只需要把过程中的 `@action` 判断替换成 `@lx`。

```
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_demo_book_modify
    @action VARCHAR(20) = '',
    @lx VARCHAR(20) = '',
    @rcaption NVARCHAR(100) = '',

    @args1 NVARCHAR(500) = '',

    @edit1 NVARCHAR(500) = '',
    @edit2 NVARCHAR(500) = '',
    @edit3 NVARCHAR(500) = '',
    @edit4 NVARCHAR(500) = '',
    @edit5 NVARCHAR(500) = '',

    @pkey1 NVARCHAR(500) = '',
    @pkey2 NVARCHAR(500) = '',

    @clyj1 NVARCHAR(500) = '',
    @clyj2 NVARCHAR(500) = '',

    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',

    @flag_sm NVARCHAR(1000) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;

    DECLARE @book_code VARCHAR(20);
    DECLARE @book_price DECIMAL(10,2);
    DECLARE @biz_action VARCHAR(20);

    SET @flag_sm = N'';

    SET @biz_action =
        LOWER
        (
            LTRIM
            (
                RTRIM
                (
                    ISNULL(@action, '')
                )
            )
        );

    /* 兼容中文右键菜单名称 */
    IF @biz_action IN ('', 'cz')
    BEGIN
        SET @biz_action =
            CASE
                WHEN @rcaption IN (N'新增', N'新增图书')
                    THEN 'add'

                WHEN @rcaption IN (N'修改', N'修改图书')
                    THEN 'update'

                WHEN @rcaption IN (N'删除', N'删除图书')
                    THEN 'delete'

                ELSE @biz_action
            END;
    END;

    /*==================================================
      一、新增
    ==================================================*/
    IF @biz_action IN ('add', 'xz', 'insert')
    BEGIN
        SET @book_code =
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'');

        IF @book_code IS NULL
        BEGIN
            SET @flag_sm = N'新增失败：图书编号不能为空。';
            RETURN;
        END;

        IF NULLIF(LTRIM(RTRIM(ISNULL(@edit2, N''))), N'') IS NULL
        BEGIN
            SET @flag_sm = N'新增失败：图书名称不能为空。';
            RETURN;
        END;

        IF EXISTS
        (
            SELECT 1
            FROM dbo.t_demo_book
            WHERE book_code = @book_code
        )
        BEGIN
            SET @flag_sm =
                N'新增失败：图书编号【'
                + @book_code
                + N'】已经存在。';

            RETURN;
        END;

        SET @book_price =
            CASE
                WHEN ISNULL(LTRIM(RTRIM(@edit3)), '') = ''
                    THEN NULL
                ELSE TRY_CONVERT(DECIMAL(10,2), @edit3)
            END;

        IF ISNULL(LTRIM(RTRIM(@edit3)), '') <> ''
           AND @book_price IS NULL
        BEGIN
            SET @flag_sm = N'新增失败：图书价格必须是数字。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            INSERT INTO dbo.t_demo_book
            (
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj
            )
            VALUES
            (
                @book_code,
                @edit2,
                @book_price,
                0,
                NULL,
                @czydm,
                @czyxm,
                GETDATE()
            );

            INSERT INTO dbo.t_demo_book_backup
            (
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj,

                operation_type,
                operation_user_code,
                operation_user_name,
                operation_time,
                operation_note
            )
            SELECT
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj,

                N'新增',
                @czydm,
                @czyxm,
                GETDATE(),
                N'新增图书'
            FROM dbo.t_demo_book
            WHERE book_code = @book_code;

            COMMIT TRAN;

            SET @flag_sm =
                N'图书【'
                + @book_code
                + N'】新增成功。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'新增失败：'
                + ERROR_MESSAGE();

            RETURN;
        END CATCH;
    END;

    /*==================================================
      二、修改
    ==================================================*/
    ELSE IF @biz_action IN ('update', 'xg', 'edit')
    BEGIN
        SET @book_code =
            COALESCE
            (
                NULLIF(LTRIM(RTRIM(ISNULL(@pkey1, N''))), N''),
                NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
                NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
            );

        IF ISNULL(@book_code, '') = ''
        BEGIN
            SET @flag_sm = N'修改失败：没有获取到图书编号。';
            RETURN;
        END;

        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_demo_book
            WHERE book_code = @book_code
              AND flag_zf = 0
        )
        BEGIN
            SET @flag_sm = N'修改失败：图书不存在或已经删除。';
            RETURN;
        END;

        IF NULLIF(LTRIM(RTRIM(ISNULL(@edit2, N''))), N'') IS NULL
        BEGIN
            SET @flag_sm = N'修改失败：图书名称不能为空。';
            RETURN;
        END;

        SET @book_price =
            CASE
                WHEN ISNULL(LTRIM(RTRIM(@edit3)), '') = ''
                    THEN NULL
                ELSE TRY_CONVERT(DECIMAL(10,2), @edit3)
            END;

        IF ISNULL(LTRIM(RTRIM(@edit3)), '') <> ''
           AND @book_price IS NULL
        BEGIN
            SET @flag_sm = N'修改失败：图书价格必须是数字。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            /* 修改前记录旧数据 */
            INSERT INTO dbo.t_demo_book_backup
            (
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj,

                operation_type,
                operation_user_code,
                operation_user_name,
                operation_time,
                operation_note
            )
            SELECT
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj,

                N'修改',
                @czydm,
                @czyxm,
                GETDATE(),
                N'修改前数据'
            FROM dbo.t_demo_book
            WHERE book_code = @book_code;

            UPDATE dbo.t_demo_book
            SET
                book_name = @edit2,
                book_price = @book_price,
                czydm_dj = @czydm,
                czyxm_dj = @czyxm,
                time_dj = GETDATE()
            WHERE book_code = @book_code
              AND flag_zf = 0;

            COMMIT TRAN;

            SET @flag_sm =
                N'图书【'
                + @book_code
                + N'】修改成功。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'修改失败：'
                + ERROR_MESSAGE();

            RETURN;
        END CATCH;
    END;

    /*==================================================
      三、删除
    ==================================================*/
    ELSE IF @biz_action IN ('delete', 'sc', 'remove')
    BEGIN
        SET @book_code =
            COALESCE
            (
                NULLIF(LTRIM(RTRIM(ISNULL(@pkey1, N''))), N''),
                NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N'')
            );

        IF ISNULL(@book_code, '') = ''
        BEGIN
            SET @flag_sm = N'删除失败：没有获取到图书编号。';
            RETURN;
        END;

        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_demo_book
            WHERE book_code = @book_code
              AND flag_zf = 0
        )
        BEGIN
            SET @flag_sm = N'删除失败：图书不存在或已经删除。';
            RETURN;
        END;

        IF ISNULL(LTRIM(RTRIM(@clyj1)), '') = ''
        BEGIN
            SET @flag_sm = N'删除失败：请填写删除原因。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            /* 删除前备份 */
            INSERT INTO dbo.t_demo_book_backup
            (
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj,

                operation_type,
                operation_user_code,
                operation_user_name,
                operation_time,
                operation_note
            )
            SELECT
                book_code,
                book_name,
                book_price,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj,

                N'删除',
                @czydm,
                @czyxm,
                GETDATE(),
                @clyj1
            FROM dbo.t_demo_book
            WHERE book_code = @book_code;

            /* 逻辑删除 */
            UPDATE dbo.t_demo_book
            SET
                flag_zf = 1,
                bz_zf = @clyj1,
                czydm_dj = @czydm,
                czyxm_dj = @czyxm,
                time_dj = GETDATE()
            WHERE book_code = @book_code
              AND flag_zf = 0;

            COMMIT TRAN;

            SET @flag_sm =
                N'图书【'
                + @book_code
                + N'】删除成功。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'删除失败：'
                + ERROR_MESSAGE();

            RETURN;
        END CATCH;
    END;

    SET @flag_sm =
        N'没有识别到业务操作，当前action='
        + ISNULL(@action, N'NULL')
        + N'，当前菜单='
        + ISNULL(@rcaption, N'NULL');

# 十一、上下选查询存储过程

上下选查询必须返回两个结果集：

```
第一个SELECT：上方未选标签
第二个SELECT：下方已选标签
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_demo_book_tag_query
    @args1 NVARCHAR(500) = '',

    @edit1 NVARCHAR(500) = '',
    @edit2 NVARCHAR(500) = '',
    @edit3 NVARCHAR(500) = '',

    @pkey1 NVARCHAR(500) = '',

    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',

    @flag_sm NVARCHAR(1000) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @book_code VARCHAR(20);
    DECLARE @tag_keyword NVARCHAR(100);

    SET @flag_sm = N'';

    /* 优先取主页面右键传入的args1 */
    SET @book_code =
        COALESCE
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    SET @tag_keyword =
        NULLIF(LTRIM(RTRIM(ISNULL(@edit2, N''))), N'');

    IF ISNULL(@book_code, '') = ''
    BEGIN
        SET @flag_sm = N'没有获取到图书编号。';

        SELECT
            CAST('' AS VARCHAR(20)) AS [标签编号],
            CAST(N'' AS NVARCHAR(100)) AS [标签名称]
        WHERE 1 = 0;

        SELECT
            CAST('' AS VARCHAR(20)) AS [标签编号],
            CAST(N'' AS NVARCHAR(100)) AS [标签名称]
        WHERE 1 = 0;

        RETURN;
    END;

    /*==================================================
      结果集1：上方未选择标签
    ==================================================*/
    SELECT
        t.tag_code AS [标签编号],
        t.tag_name AS [标签名称]

    FROM dbo.t_demo_tag t WITH(NOLOCK)

    WHERE t.flag_enable = 1
      AND t.flag_zf = 0

      AND
      (
          @tag_keyword IS NULL
          OR t.tag_code LIKE '%' + @tag_keyword + '%'
          OR t.tag_name LIKE N'%' + @tag_keyword + N'%'
      )

      AND NOT EXISTS
      (
          SELECT 1
          FROM dbo.t_demo_book_tag_gx g WITH(NOLOCK)
          WHERE g.book_code = @book_code
            AND g.tag_code = t.tag_code
            AND g.czydm_gx = @czydm
      )

    ORDER BY t.sort_no, t.tag_code;

    /*==================================================
      结果集2：下方已选择标签
    ==================================================*/
    SELECT DISTINCT
        t.tag_code AS [标签编号],
        t.tag_name AS [标签名称]

    FROM dbo.t_demo_book_tag_gx g WITH(NOLOCK)

    INNER JOIN dbo.t_demo_tag t WITH(NOLOCK)
        ON t.tag_code = g.tag_code

    WHERE g.book_code = @book_code
      AND g.czydm_gx = @czydm

    ORDER BY t.tag_code;
END
GO
```

# 十二、上下选操作存储过程

```
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_demo_book_tag_modify
    @fs VARCHAR(20) = '',

    @args1 NVARCHAR(500) = '',

    @edit1 NVARCHAR(500) = '',
    @edit2 NVARCHAR(500) = '',
    @edit3 NVARCHAR(500) = '',

    @pkey1 NVARCHAR(500) = '',
    @pkey2 NVARCHAR(500) = '',

    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',

    @flag_sm NVARCHAR(1000) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;

    DECLARE @book_code VARCHAR(20);
    DECLARE @now DATETIME = GETDATE();

    SET @flag_sm = N'';

    SET @book_code =
        COALESCE
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    IF ISNULL(@book_code, '') = ''
    BEGIN
        SET @flag_sm = N'没有获取到图书编号。';
        RETURN;
    END;

    /*==================================================
      一、初始化
    ==================================================*/
    IF @fs = 'load'
    BEGIN
        DELETE FROM dbo.t_demo_book_tag_gx
        WHERE book_code = @book_code
          AND czydm_gx = @czydm;

        INSERT INTO dbo.t_demo_book_tag_gx
        (
            book_code,
            tag_code,
            czydm_gx,
            time_gx
        )
        SELECT DISTINCT
            r.book_code,
            r.tag_code,
            @czydm,
            @now
        FROM dbo.t_demo_book_tag_rel r
        WHERE r.book_code = @book_code;

        SET @flag_sm = N'标签初始化完成。';
        RETURN;
    END;

    /*==================================================
      二、单选
    ==================================================*/
    ELSE IF @fs = 'dx'
    BEGIN
        IF ISNULL(LTRIM(RTRIM(@pkey1)), '') = ''
        BEGIN
            SET @flag_sm = N'请选择需要下移的标签。';
            RETURN;
        END;

        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_demo_book_tag_gx
            WHERE book_code = @book_code
              AND tag_code = @pkey1
              AND czydm_gx = @czydm
        )
        BEGIN
            INSERT INTO dbo.t_demo_book_tag_gx
            (
                book_code,
                tag_code,
                czydm_gx,
                time_gx
            )
            VALUES
            (
                @book_code,
                @pkey1,
                @czydm,
                @now
            );
        END;

        SET @flag_sm = N'单选成功。';
        RETURN;
    END;

    /*==================================================
      三、全选
    ==================================================*/
    ELSE IF @fs = 'qx'
    BEGIN
        BEGIN TRY
            BEGIN TRAN;

            /* 清空当前用户、当前图书的临时数据 */
            DELETE FROM dbo.t_demo_book_tag_gx
            WHERE book_code = @book_code
              AND czydm_gx = @czydm;

            /*
                全选必须使用标签表中的t.tag_code，
                不能使用@pkey1。
            */
            INSERT INTO dbo.t_demo_book_tag_gx
            (
                book_code,
                tag_code,
                czydm_gx,
                time_gx
            )
            SELECT DISTINCT
                @book_code,
                t.tag_code,
                @czydm,
                @now
            FROM dbo.t_demo_tag t
            WHERE t.flag_enable = 1
              AND t.flag_zf = 0
              AND ISNULL(LTRIM(RTRIM(t.tag_code)), '') <> '';

            DECLARE @qx_count INT = @@ROWCOUNT;

            COMMIT TRAN;

            SET @flag_sm =
                N'全选成功，共选择'
                + CONVERT(NVARCHAR(20), @qx_count)
                + N'个标签。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'全选失败：'
                + ERROR_MESSAGE();

            RETURN;
        END CATCH;
    END;

    /*==================================================
      四、单删
    ==================================================*/
    ELSE IF @fs = 'ds'
    BEGIN
        IF ISNULL(LTRIM(RTRIM(@pkey1)), '') = ''
        BEGIN
            SET @flag_sm = N'请选择需要上移的标签。';
            RETURN;
        END;

        DELETE FROM dbo.t_demo_book_tag_gx
        WHERE book_code = @book_code
          AND tag_code = @pkey1
          AND czydm_gx = @czydm;

        SET @flag_sm = N'单删成功。';
        RETURN;
    END;

    /*==================================================
      五、全删
    ==================================================*/
    ELSE IF @fs = 'qs'
    BEGIN
        DELETE FROM dbo.t_demo_book_tag_gx
        WHERE book_code = @book_code
          AND czydm_gx = @czydm;

        SET @flag_sm = N'全部标签已经清空。';
        RETURN;
    END;

    /*==================================================
      六、保存
    ==================================================*/
    ELSE IF @fs = 'save'
    BEGIN
        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_demo_book
            WHERE book_code = @book_code
              AND flag_zf = 0
        )
        BEGIN
            SET @flag_sm = N'保存失败：图书不存在或已经删除。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            /* 删除原正式关系 */
            DELETE FROM dbo.t_demo_book_tag_rel
            WHERE book_code = @book_code;

            /* 保存当前临时选择 */
            INSERT INTO dbo.t_demo_book_tag_rel
            (
                book_code,
                tag_code,
                czydm_dj,
                czyxm_dj,
                time_dj
            )
            SELECT DISTINCT
                g.book_code,
                g.tag_code,
                @czydm,
                @czyxm,
                @now
            FROM dbo.t_demo_book_tag_gx g

            INNER JOIN dbo.t_demo_tag t
                ON t.tag_code = g.tag_code

            WHERE g.book_code = @book_code
              AND g.czydm_gx = @czydm
              AND t.flag_enable = 1
              AND t.flag_zf = 0
              AND ISNULL(LTRIM(RTRIM(g.tag_code)), '') <> '';

            DECLARE @save_count INT = @@ROWCOUNT;

            DELETE FROM dbo.t_demo_book_tag_gx
            WHERE book_code = @book_code
              AND czydm_gx = @czydm;

            COMMIT TRAN;

            SET @flag_sm =
                N'保存成功，共保存'
                + CONVERT(NVARCHAR(20), @save_count)
                + N'个标签。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'保存失败：'
                + ERROR_MESSAGE();

            RETURN;
        END CATCH;
    END;

    SET @flag_sm =
        N'没有识别到上下选操作，当前fs='
        + ISNULL(@fs, N'NULL');
END
GO

# 十七、上下选页面控件配置

上下选页面名称：

```
图书标签上下选
```

主键：

```
标签编号
```

查询控件可以配置：

| xh   | 控件     | 参数     |
| ---- | -------- | -------- |
| 10   | 图书编号 | `@edit1` |
| 20   | 标签信息 | `@edit2` |
| 999  | 查询按钮 | 查询     |

但是右键打开时，真正的图书编号优先来自：

```
@args1
```

过程统一使用：

```
COALESCE
(
    NULLIF(@args1, ''),
    NULLIF(@edit1, '')
)
```

因此即使页面上的图书编号没有手工填写，也能正确查询。

# 二十、整个案例的最终流程

## 主页面查询

```
用户填写查询条件
→ base_ggmkdetail中的cx控件
→ @edit1、@edit2、@edit3
→ 路由action=cx
→ p_demo_book_query
→ 返回图书列表
```

## 查看明细

```
选中图书
→ 当前行图书编号进入@pkey1
→ 路由action=mx
→ p_demo_book_detail
→ 返回单条数据
```

## 新增

```
点击新增
→ 新增控件生成@edit1～@edit3
→ 路由action=cz
→ p_demo_book_modify
→ @action=add
→ 插入主表
→ 写入操作记录
```

## 修改

```
选中图书
→ mx查询原数据
→ 数据回填修改窗口
→ 用户修改
→ 路由action=cz
→ @action=update
→ 修改前写入操作记录
→ 更新主表
```

## 删除

```
选中图书
→ 删除原因进入@clyj1
→ 图书编号进入@pkey1
→ 路由action=cz
→ @action=delete
→ 删除前写入操作记录
→ flag_zf改为1
```

## 上下选

```
选中图书
→ 右键图书标签管理
→ base_ggmkright.lx=6
→ 图书编号传入@args1
→ 打开图书标签上下选
→ cx路由调用查询过程
→ cz路由调用操作过程
→ save写入正式关系表
```

# 二十一、这个案例最需要记住的十条规则

1. 主页面 `pkey` 必须和查询结果列名完全一致。
2. 本案例主页面主键列统一叫“图书编号”。
3. 查询、新增、修改的普通字段使用 `@editN`。
4. 删除原因、处理意见使用 `@clyjN`。
5. 当前选中行主键使用 `@pkey1`。
6. 从主页面传到上下选页面的数据使用 `@args1`。
7. 上下选查询过程必须返回两个结果集。
8. 全选时必须使用标签表的 `t.tag_code`，不能使用 `@pkey1`。
9. 临时表负责页面选择过程，正式关系表负责最终保存结果。
10. 查询、明细、操作、上下选过程都通过路由表调用。

这个案例学会以后，换成车辆、员工、合同、物资、客户等业务时，只需要替换表名和字段名，整体开发流程不变。
