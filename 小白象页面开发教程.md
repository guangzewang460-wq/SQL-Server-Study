# 设备台账主页面完整开发教程

下面继续使用你现在已经完成的设备台账案例，完整梳理主页面的：

```
查询
明细查看
新增
修改
删除
操作记录
设备标签显示
动态路由
右键菜单
```

整体调用关系如下：

```
base_ggmkmain
    ↓
定义“设备台账管理”主页面

base_ggmkdetail
    ↓
定义查询框、新增框、修改框等控件

base_ggmkright
    ↓
定义查看明细、修改、删除、查看操作记录、设备标签管理

t_ggmk_routes
    ↓
根据cx、mx、cz找到业务存储过程

TEST.dbo.p_equipment_cx
    ↓
统一执行查询、明细、新增、修改、删除
```

------

# 一、最终功能目标

进入“设备台账管理”页面后，应具备以下功能：

| 功能         | 操作方式                 |
| ------------ | ------------------------ |
| 查询设备     | 主页面上方查询条件       |
| 查看明细     | 双击或右键“查看明细”     |
| 新增设备     | 点击新增按钮             |
| 修改设备     | 选中设备，右键修改       |
| 删除设备     | 选中设备，右键删除       |
| 查看操作记录 | 选中设备，右键查看记录   |
| 设备标签管理 | 选中设备，右键打开上下选 |
| 显示设备标签 | 主页面查询结果直接显示   |

# 三、设备主表设计

如果你的表已经存在，不需要重新创建。下面主要用于说明字段对应关系。

```
USE TEST;
GO

CREATE TABLE dbo.t_equipment
(
    iid BIGINT IDENTITY(1,1) NOT NULL
        CONSTRAINT PK_t_equipment PRIMARY KEY,

    equipment_code VARCHAR(30) NOT NULL,
    equipment_name NVARCHAR(100) NOT NULL,
    model_spec NVARCHAR(100) NULL,
    department_name NVARCHAR(100) NULL,
    keeper_name NVARCHAR(50) NULL,

    purchase_date DATE NULL,
    equipment_status NVARCHAR(30) NULL,
    equipment_price DECIMAL(18,2) NULL,
    equipment_remark NVARCHAR(500) NULL,

    flag_zf SMALLINT NOT NULL
        CONSTRAINT DF_t_equipment_flag_zf DEFAULT(0),

    bz_zf NVARCHAR(500) NULL,

    czydm_dj VARCHAR(20) NOT NULL,
    czyxm_dj NVARCHAR(50) NOT NULL,
    time_dj DATETIME NOT NULL
        CONSTRAINT DF_t_equipment_time_dj DEFAULT(GETDATE()),

    CONSTRAINT UQ_t_equipment_code
        UNIQUE(equipment_code)
);
GO
```

## 字段含义

| 字段               | 含义                   |

| `department_name`  | 使用部门               |
| `keeper_name`      | 负责人                 |

| `equipment_status` | 设备状态               |
| `equipment_price`  | 设备价格               |

| `czydm_dj`         | 最后操作人工号         |
| `czyxm_dj`         | 最后操作人姓名         |
| `time_dj`          | 最后操作时间           |

# 七、查询控件配置

查询区域建议设置以下控件。

| 顺序 | 控件名称 | 参数     |
| ---- | -------- | -------- |
| 10   | 设备编号 | `@edit1` |
| 20   | 设备名称 | `@edit2` |
| 30   | 型号规格 | `@edit3` |
| 40   | 使用部门 | `@edit4` |
| 50   | 负责人   | `@edit5` |
| 60   | 设备状态 | `@edit6` |
| 70   | 记录状态 | `@edit7` |
| 999  | 查询按钮 | 执行查询 |

在 `base_ggmkdetail` 中，查询控件通常使用：

```
lx = cx
```

控件顺序 `xh` 决定参数顺序：

```
第一个查询控件  → @edit1
第二个查询控件  → @edit2
第三个查询控件  → @edit3
……
```

因此配置时不能随意更换顺序。

检查当前查询控件：

```
SELECT
    rid,
    iid,
    lx,
    xh,
    caption,
    controltype,
    mrz
FROM PUBLIC_CS.dbo.base_ggmkdetail
WHERE iid = 1049
  AND lx = 'cx'
ORDER BY xh;
```

实际字段名如果与你系统不同，以现有表结构为准。

| 80   | 设备价格 |
| 90   | 设备备注 |

通常可以采用：

```
新增表单：lx = xz
修改表单：lx = r
```

修改表单打开时，需要通过明细查询把原数据回填到控件中。

注意：

```
新增时设备编号允许输入
修改时设备编号建议只读
```

因为设备编号属于业务主键，不建议修改。

# 九、动态路由配置

主页面查询、明细和操作都指向同一个业务过程：

```
TEST.dbo.p_equipment_cx
```

三种路由：

| action | 作用             |
| ------ | ---------------- |
| `cx`   | 主页面查询       |
| `mx`   | 查询单条设备明细 |
| `cz`   | 新增、修改、删除 |

先检查当前路由：

```
USE PUBLIC_CS;
GO

SELECT
    iid,
    lx,
    pname,
    action,
    jmlx
FROM dbo.t_ggmk_routes
WHERE lx = N'设备台账管理'
ORDER BY action;
```

参考配置：

```
USE PUBLIC_CS;
GO

DELETE FROM dbo.t_ggmk_routes
WHERE lx = N'设备台账管理'
  AND action IN ('cx', 'mx', 'cz');

DECLARE @max_iid INT;

SELECT @max_iid = ISNULL(MAX(iid), 0)
FROM dbo.t_ggmk_routes;

INSERT INTO dbo.t_ggmk_routes
(
    iid,
    lx,
    pname,
    action,
    jmlx,
    czydm_dj,
    czyxm_dj,
    djsj
)
SELECT
    @max_iid + 1,
    N'设备台账管理',
    N'TEST.dbo.p_equipment_cx',
    'cx',
    N'普通界面',
    '1561',
    N'测试',
    GETDATE()

UNION ALL

SELECT
    @max_iid + 2,
    N'设备台账管理',
    N'TEST.dbo.p_equipment_cx',
    'mx',
    N'普通界面',
    '1561',
    N'测试',
    GETDATE()

UNION ALL

SELECT
    @max_iid + 3,
    N'设备台账管理',
    N'TEST.dbo.p_equipment_cx',
    'cz',
    N'普通界面',
    '1561',
    N'测试',
    GETDATE();
GO
```

如果你当前系统普通页面的 `jmlx` 不是“普通界面”，应复制其他正常主页面使用的 `jmlx` 值。

# 十、主页面统一存储过程

下面是查询、明细、新增、修改、删除统一处理的完整模板。

注意：

```
@ggmk_lx = cx、mx、cz
@action   = add、update、delete
```

如果你的公共过程实际传入的参数名称不是 `@ggmk_lx`，而是 `@lx`，只需将判断变量替换为实际参数。

```
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_equipment_cx
    /* 页面路由参数 */
    @ggmk_lx VARCHAR(20) = '',
    @action VARCHAR(20) = '',
    @lx VARCHAR(20) = '',
    @rcaption NVARCHAR(100) = '',
    @dgvindex INT = 0,

    /* 右键或窗口传入参数 */
    @args1 NVARCHAR(500) = '',
    @args2 NVARCHAR(500) = '',
    @args3 NVARCHAR(500) = '',
    @args4 NVARCHAR(500) = '',
    @args5 NVARCHAR(500) = '',

    /* 页面输入参数 */
    @edit1 NVARCHAR(500) = '',
    @edit2 NVARCHAR(500) = '',
    @edit3 NVARCHAR(500) = '',
    @edit4 NVARCHAR(500) = '',
    @edit5 NVARCHAR(500) = '',
    @edit6 NVARCHAR(500) = '',
    @edit7 NVARCHAR(500) = '',
    @edit8 NVARCHAR(500) = '',
    @edit9 NVARCHAR(500) = '',
    @edit10 NVARCHAR(500) = '',
    @edit11 NVARCHAR(500) = '',
    @edit12 NVARCHAR(500) = '',
    @edit13 NVARCHAR(500) = '',
    @edit14 NVARCHAR(500) = '',
    @edit15 NVARCHAR(500) = '',

    /* 当前行主键 */
    @pkey1 NVARCHAR(500) = '',
    @pkey2 NVARCHAR(500) = '',
    @pkey3 NVARCHAR(500) = '',
    @pkey4 NVARCHAR(500) = '',
    @pkey5 NVARCHAR(500) = '',

    /* 当前操作人 */
    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',

    /* 返回提示 */
    @flag_sm NVARCHAR(1000) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;

    DECLARE @equipment_code VARCHAR(30);
    DECLARE @purchase_date DATE;
    DECLARE @equipment_price DECIMAL(18,2);
    DECLARE @operation VARCHAR(20);

    SET @flag_sm = N'';

    /* 兼容不同方式传入设备编号 */
    SET @equipment_code =
        COALESCE
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@pkey1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    SET @operation =
        LOWER
        (
            LTRIM
            (
                RTRIM
                (
                    ISNULL(@action, '')
                )
            )
        );

    /* 兼容中文右键名称 */
    IF @operation = ''
    BEGIN
        SET @operation =
            CASE
                WHEN @rcaption IN (N'新增', N'新增设备')
                    THEN 'add'

                WHEN @rcaption IN (N'修改', N'修改设备')
                    THEN 'update'

                WHEN @rcaption IN (N'删除', N'删除设备')
                    THEN 'delete'

                ELSE ''
            END;
    END;

    /*====================================================
      一、主页面查询
    ====================================================*/
    IF @ggmk_lx = 'cx'
    BEGIN
        SELECT
            a.equipment_code AS [设备编号],
            a.equipment_name AS [设备名称],
            a.model_spec AS [型号规格],
            a.department_name AS [使用部门],
            a.keeper_name AS [负责人],

            CONVERT(VARCHAR(10), a.purchase_date, 120)
                AS [购置日期],

            a.equipment_status AS [设备状态],
            a.equipment_price AS [设备价格],

            /* 合并显示设备标签 */
            ISNULL
            (
                (
                    SELECT
                        STRING_AGG
                        (
                            CONVERT(NVARCHAR(MAX), t.tag_name),
                            N'、'
                        )
                        WITHIN GROUP
                        (
                            ORDER BY t.sort_no, t.tag_code
                        )
                    FROM dbo.t_equipment_tag_rel r

                    INNER JOIN dbo.t_equipment_tag t
                        ON t.tag_code = r.tag_code

                    WHERE r.equipment_code = a.equipment_code
                      AND t.flag_enable = 1
                      AND t.flag_zf = 0
                ),
                N''
            ) AS [设备标签],

            a.equipment_remark AS [设备备注],

            CASE a.flag_zf
                WHEN 1 THEN N'已删除'
                ELSE N'正常'
            END AS [记录状态],

            a.czydm_dj AS [登记人工号],
            a.czyxm_dj AS [登记人姓名],

            CONVERT(VARCHAR(19), a.time_dj, 120)
                AS [登记时间]

        FROM dbo.t_equipment a WITH(NOLOCK)

        WHERE
            (
                ISNULL(@edit1, '') = ''
                OR a.equipment_code LIKE '%' + @edit1 + '%'
            )

            AND
            (
                ISNULL(@edit2, '') = ''
                OR a.equipment_name LIKE N'%' + @edit2 + N'%'
            )

            AND
            (
                ISNULL(@edit3, '') = ''
                OR a.model_spec LIKE N'%' + @edit3 + N'%'
            )

            AND
            (
                ISNULL(@edit4, '') = ''
                OR a.department_name = @edit4
            )

            AND
            (
                ISNULL(@edit5, '') = ''
                OR a.keeper_name LIKE N'%' + @edit5 + N'%'
            )

            AND
            (
                ISNULL(@edit6, '') = ''
                OR a.equipment_status = @edit6
            )

            AND
            (
                (
                    ISNULL(@edit7, '') IN ('', N'正常')
                    AND a.flag_zf = 0
                )

                OR
                (
                    @edit7 = N'已删除'
                    AND a.flag_zf = 1
                )

                OR
                (
                    @edit7 = N'全部'
                )
            )

        ORDER BY a.equipment_code;

        RETURN;
    END;

    /*====================================================
      二、明细查询
    ====================================================*/
    ELSE IF @ggmk_lx = 'mx'
    BEGIN
        IF ISNULL(@equipment_code, '') = ''
        BEGIN
            SET @flag_sm = N'查看明细失败：没有获取到设备编号。';
            RETURN;
        END;

        SELECT
            a.equipment_code AS [设备编号],
            a.equipment_name AS [设备名称],
            a.model_spec AS [型号规格],
            a.department_name AS [使用部门],
            a.keeper_name AS [负责人],

            CONVERT(VARCHAR(10), a.purchase_date, 120)
                AS [购置日期],

            a.equipment_status AS [设备状态],
            a.equipment_price AS [设备价格],
            a.equipment_remark AS [设备备注],

            CASE a.flag_zf
                WHEN 1 THEN N'已删除'
                ELSE N'正常'
            END AS [记录状态],

            a.bz_zf AS [删除原因],
            a.czydm_dj AS [登记人工号],
            a.czyxm_dj AS [登记人姓名],

            CONVERT(VARCHAR(19), a.time_dj, 120)
                AS [登记时间]

        FROM dbo.t_equipment a WITH(NOLOCK)

        WHERE a.equipment_code = @equipment_code;

        IF @@ROWCOUNT = 0
        BEGIN
            SET @flag_sm = N'没有找到设备编号：'
                + ISNULL(@equipment_code, '');
        END;

        RETURN;
    END;

    /*====================================================
      三、业务操作入口
    ====================================================*/
    ELSE IF @ggmk_lx = 'cz'
    BEGIN
        /* 继续执行下面的add、update、delete */
        SET @operation =
            CASE
                WHEN @operation IN ('add', 'xz', 'insert')
                    THEN 'add'

                WHEN @operation IN ('update', 'xg', 'edit')
                    THEN 'update'

                WHEN @operation IN ('delete', 'sc', 'remove')
                    THEN 'delete'

                ELSE @operation
            END;
    END
    ELSE
    BEGIN
        SET @flag_sm =
            N'未识别的页面操作类型：'
            + ISNULL(@ggmk_lx, N'NULL');

        RETURN;
    END;

    /*====================================================
      四、新增设备
    ====================================================*/
    IF @operation = 'add'
    BEGIN
        SET @equipment_code =
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'');

        IF @equipment_code IS NULL
        BEGIN
            SET @flag_sm = N'新增失败：设备编号不能为空。';
            RETURN;
        END;

        IF NULLIF(LTRIM(RTRIM(ISNULL(@edit2, N''))), N'') IS NULL
        BEGIN
            SET @flag_sm = N'新增失败：设备名称不能为空。';
            RETURN;
        END;

        IF EXISTS
        (
            SELECT 1
            FROM dbo.t_equipment
            WHERE equipment_code = @equipment_code
        )
        BEGIN
            SET @flag_sm =
                N'新增失败：设备编号【'
                + @equipment_code
                + N'】已经存在。';

            RETURN;
        END;

        SET @purchase_date =
            CASE
                WHEN ISNULL(LTRIM(RTRIM(@edit6)), '') = ''
                    THEN NULL
                ELSE TRY_CONVERT(DATE, @edit6, 120)
            END;

        IF ISNULL(LTRIM(RTRIM(@edit6)), '') <> ''
           AND @purchase_date IS NULL
        BEGIN
            SET @flag_sm =
                N'新增失败：购置日期格式不正确，应为yyyy-MM-dd。';

            RETURN;
        END;

        SET @equipment_price =
            CASE
                WHEN ISNULL(LTRIM(RTRIM(@edit8)), '') = ''
                    THEN NULL
                ELSE TRY_CONVERT(DECIMAL(18,2), @edit8)
            END;

        IF ISNULL(LTRIM(RTRIM(@edit8)), '') <> ''
           AND @equipment_price IS NULL
        BEGIN
            SET @flag_sm = N'新增失败：设备价格必须是数字。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            INSERT INTO dbo.t_equipment
            (
                equipment_code,
                equipment_name,
                model_spec,
                department_name,
                keeper_name,
                purchase_date,
                equipment_status,
                equipment_price,
                equipment_remark,
                flag_zf,
                bz_zf,
                czydm_dj,
                czyxm_dj,
                time_dj
            )
            VALUES
            (
                @equipment_code,
                @edit2,
                NULLIF(@edit3, N''),
                NULLIF(@edit4, N''),
                NULLIF(@edit5, N''),
```

# 十一、为什么查询和新增都使用了 `@edit1`

这是公共配置页面常见的参数方式。

查询模式：

```
lx=cx
第一个查询控件 → @edit1
```

新增模式：

```
lx=xz
第一个新增控件 → @edit1
```

修改模式：

```
lx=r
第一个修改控件 → @edit1
```

虽然参数名称相同，但每次只会提交当前窗口中的控件，因此不会冲突。

# 十二、右键菜单配置思路

建议主页面配置以下右键菜单：

| 顺序 | 菜单名称     | 功能               |
| ---- | ------------ | ------------------ |
| 1    | 查看明细     | 调用 `mx`          |
| 2    | 修改设备     | 调用 `cz + update` |
| 3    | 删除设备     | 调用 `cz + delete` |
| 4    | 查看操作记录 | 打开操作记录页面   |
| 5    | 设备标签管理 | `lx=6`打开上下选   |

检查现有右键：

```
SELECT
    cid,
    iid,
    xh,
    rcaption,
    rname,
    lx,
    pkey,
    clyj,
    toform,
    toformarg,
    toformargxml
FROM PUBLIC_CS.dbo.base_ggmkright
WHERE iid = 1049
ORDER BY xh;
```

## 关键点

修改和删除菜单都要能够取得：

```
当前行设备编号
```

所以：

```
pkey = 设备编号
```

设备主查询结果也必须有：

```
设备编号
```

修改菜单需要将业务动作传给过程：

```
@action = update
```

删除菜单需要传：

```
@action = delete
```

具体 XML 或 `clyj` 写法，应复制你系统里已经正常运行的修改、删除右键配置，只替换：

```
页面名称
主键名称
action值
目标rid
```

因为不同版本公共平台的 XML 属性名称可能不完全一致。

打开修改窗口时，系统通常先调用：

# 十四、设备操作记录查询过程

设备操作记录可以通过右键打开独立明细页面。

```
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_equipment_backup_query
    @args1 NVARCHAR(500) = '',
    @edit1 NVARCHAR(500) = '',
    @pkey1 NVARCHAR(500) = '',
    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',
    @flag_sm NVARCHAR(500) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @equipment_code VARCHAR(30);

    SET @flag_sm = N'';

    SET @equipment_code =
        COALESCE
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@pkey1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    SELECT
        b.equipment_code AS [设备编号],
        b.equipment_name AS [设备名称],
        b.model_spec AS [型号规格],
        b.department_name AS [使用部门],
        b.keeper_name AS [负责人],

        CONVERT(VARCHAR(10), b.purchase_date, 120)
            AS [购置日期],

        b.equipment_status AS [设备状态],
        b.equipment_price AS [设备价格],
        b.equipment_remark AS [设备备注],

        b.czlx_backup AS [操作类型],
        b.czydm_backup AS [操作人工号],
        b.czyxm_backup AS [操作人姓名],

        CONVERT(VARCHAR(19), b.time_backup, 120)
            AS [操作时间],

        b.sm_backup AS [操作说明]

    FROM dbo.t_equipment_backup b WITH(NOLOCK)

    WHERE
        (
            ISNULL(@equipment_code, '') = ''
            OR b.equipment_code = @equipment_code
        )

    ORDER BY
        b.time_backup DESC,
        b.iid DESC;
END
GO
```

# 二十一、常见报错排查

## 1. 点击查询没有结果

检查：

```
SELECT *
FROM PUBLIC_CS.dbo.t_ggmk_routes
WHERE lx = N'设备台账管理'
  AND action = 'cx';
```

还要检查存储过程是否进入：

```
IF @ggmk_lx = 'cx'
```

------

## 2. 修改窗口不回显数据

检查：

```
base_ggmkmain.pkey = 设备编号
查询结果列名       = 设备编号
base_ggmkright.pkey = 设备编号
```

并确认：

```
@pkey1
```

确实收到了当前设备编号。

------

## 3. 修改时设备编号为空

不要只从 `@edit1` 读取主键。

应兼容：

```
COALESCE
(
    NULLIF(@pkey1, ''),
    NULLIF(@args1, ''),
    NULLIF(@edit1, '')
)
```

------

## 4. 删除没有提示框

检查删除右键是否关联了：

```
lx = r
```

以及对应的 `base_ggmkdetail.rid` 是否存在。

------

## 5. 删除后设备仍然显示

查询时默认应限制：

```
a.flag_zf = 0
```

当前教程通过“记录状态”查询条件控制：

```
正常
已删除
全部
```

------

## 6. `@flag_sm` 返回NULL

过程开始时先写：

```
SET @flag_sm = N'';
```

每个成功或失败分支都要主动赋值。

------

## 7. 日期保存为NULL

用户输入日期应采用：

```
yyyy-MM-dd
```

转换使用：

```
TRY_CONVERT(DATE, @edit6, 120)
```

------

## 8. 设备价格报错

不要直接：

```
CONVERT(DECIMAL, @edit8)
```

应先：

```
TRY_CONVERT(DECIMAL(18,2), @edit8)
```

转换失败时返回明确提示。

# 二十二、最终验收标准

主页面开发完成后，应满足：

1. 页面能够正常打开。
2. 查询按钮能够返回设备列表。
3. 查询条件可以组合使用。
4. 主查询结果包含“设备编号”。
5. 双击或右键可以查看单条明细。
6. 新增设备后主表存在新记录。
7. 新增操作写入操作记录表。
8. 修改窗口能够正确回显原数据。
9. 修改前旧数据写入操作记录表。
10. 删除采用逻辑删除。
11. 删除前数据写入操作记录表。
12. 可以查询正常、已删除和全部记录。
13. 右键可以查看操作记录。
14. 右键可以打开设备标签上下选。
15. 主页面可以显示设备标签。
16. 所有业务过程均通过路由表调用。

整个主页面的核心结构就是：

```
主页面配置
+
查询、表单控件
+
右键菜单
+
cx、mx、cz三条路由
+
一个统一业务存储过程
+
一张主表
+
一张操作记录表
```

这样以后开发图书、人员、车辆、合同、物资等管理页面时，只需要替换业务表、字段和存储过程名称，整体开发方式完全相同。
