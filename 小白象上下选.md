# 设备标签上下选功能开发文档

## 1. 功能目标

在原有“设备台账管理”页面基础上，增加设备标签上下选功能。

最终操作流程：

```
进入设备台账管理
→ 查询设备
→ 选中一条设备记录
→ 右键“设备标签管理”
→ base_ggmkright.lx=6
→ 打开公共上下选窗口 form_common_comment
→ 上方显示可选标签
→ 下方显示当前设备已选标签
→ 支持单选、单删、全选、全删
→ 点击确认保存
→ 保存设备与标签的正式对应关系
```

本功能使用动态路由，不在公共存储过程中手工增加业务判断。

# 3. 核心参数约定

本案例统一使用以下参数：

```
@args1  = 设备台账当前行传入的设备编号
@edit1  = 上下选页面中的设备编号
@edit2  = 标签信息查询条件
@pkey1  = 当前选中标签的标签编号
@czydm  = 当前操作人工号
@czyxm  = 当前操作人姓名
@flag_sm = 返回提示信息
```

上下选操作类型：

| `@fs`  | 功能                 |
| ------ | -------------------- |
| `load` | 初始化临时选择       |
| `dx`   | 单选，向下移动一条   |
| `qx`   | 全选，全部移动到下方 |
| `ds`   | 单删，向上移动一条   |
| `qs`   | 全删，下方全部清空   |
| `save` | 保存正式设备标签关系 |

设备编号统一获取方式：

```sql
SET @equipment_code =
    COALESCE
    (
        NULLIF(LTRIM(RTRIM(ISNULL(@args1, ''))), ''),
        NULLIF(LTRIM(RTRIM(ISNULL(@edit1, ''))), '')
    );
```

含义是：

```
优先使用右键传入的@args1
@args1为空时，再使用页面中的@edit1
```

## 5.2 配置 `base_ggmkdetail`

当前页面可以保留两个查询控件：

| 顺序 | 控件     | 参数     |
| ---- | -------- | -------- |
| 10   | 设备编号 | `@edit1` |
| 20   | 标签信息 | `@edit2` |
| 999  | 查询按钮 | 执行查询 |

设备编号同时也会由右键传入 `@args1`，因此业务过程优先使用 `@args1`。

核心配置：

```sql
设备编号：
lx='cx'
controltype='textbox'
xh=10

标签信息：
lx='cx'
controltype='textbox'
xh=20

查询按钮：
lx='cx'
controltype='button'
xh=999
```

本案例不需要：

```
lx='center'
lx='bottom'
上下选页面自己的base_ggmkright
```

因为标签选择时不需要额外输入附加信息。

# 7. 配置动态路由

多选查询和操作都走路由表。

```sql
USE PUBLIC_CS;
GO

DELETE FROM dbo.t_ggmk_routes
WHERE lx = N'设备标签上下选'
  AND action IN ('cx', 'cz')
  AND jmlx LIKE N'%多选%';

DECLARE @max_iid INT;

SELECT @max_iid = ISNULL(MAX(iid), 0)
FROM dbo.t_ggmk_routes;

INSERT INTO dbo.t_ggmk_routes
(
    iid,
    lx,
    pname,
    action,
    jmlx,
    czydm_dj,
    czyxm_dj,
    djsj
)
SELECT
    @max_iid + 1,
    N'设备标签上下选',
    N'TEST.dbo.p_equipment_tag_query',
    'cx',
    N'多选界面',
    '1561',
    N'测试',
    GETDATE()

UNION ALL

SELECT
    @max_iid + 2,
    N'设备标签上下选',
    N'TEST.dbo.p_equipment_tag_modify',
    'cz',
    N'多选界面',
    '1561',
    N'测试',
    GETDATE();
GO
```

检查：

```sql
SELECT
    lx,
    pname,
    action,
    jmlx
FROM PUBLIC_CS.dbo.t_ggmk_routes
WHERE lx = N'设备标签上下选'
ORDER BY action;
```

必须有两行：

| lx             | pname                             | action | jmlx     |
| -------------- | --------------------------------- | ------ | -------- |
| 设备标签上下选 | `TEST.dbo.p_equipment_tag_query`  | `cx`   | 多选界面 |
| 设备标签上下选 | `TEST.dbo.p_equipment_tag_modify` | `cz`   | 多选界面 |

公共过程的路由条件一般包含：

```
jmlx LIKE N'%多选%'
```

因此 `jmlx` 必须包含“多选”。

# 8. 业务查询存储过程

## 8.1 重要要求

公共多选查询过程会通过动态SQL传递通用参数。

所以 `p_equipment_tag_query` 的参数头必须完整接住：

```
p_ggmk_comment_query
```

动态执行时传入的所有参数。

至少要包含：

```
@args1
@edit1、@edit2
@lx
@czydm
@czyxm
@flag_sm OUTPUT
```

曾经出现：

```
@args1不是过程p_equipment_tag_query的参数
```

就是因为业务过程没有定义 `@args1`。

下面给出业务主体完整版本。其他公共参数按实际公共过程继续补充。

```sql
USE TEST;
GO

CREATE OR ALTER PROCEDURE dbo.p_equipment_tag_query
    @args1 NVARCHAR(500) = '',
    @args2 NVARCHAR(500) = '',
    @args3 NVARCHAR(500) = '',
    @args4 NVARCHAR(500) = '',
    @args5 NVARCHAR(500) = '',
    @args6 NVARCHAR(500) = '',
    @args7 NVARCHAR(500) = '',
    @args8 NVARCHAR(500) = '',
    @args9 NVARCHAR(500) = '',
    @args10 NVARCHAR(500) = '',

    @edit1 NVARCHAR(500) = '',
    @edit2 NVARCHAR(500) = '',
    @edit3 NVARCHAR(500) = '',
    @edit4 NVARCHAR(500) = '',
    @edit5 NVARCHAR(500) = '',
    @edit6 NVARCHAR(500) = '',
    @edit7 NVARCHAR(500) = '',
    @edit8 NVARCHAR(500) = '',
    @edit9 NVARCHAR(500) = '',
    @edit10 NVARCHAR(500) = '',
    @edit11 NVARCHAR(500) = '',
    @edit12 NVARCHAR(500) = '',
    @edit13 NVARCHAR(500) = '',
    @edit14 NVARCHAR(500) = '',
    @edit15 NVARCHAR(500) = '',
    @edit16 NVARCHAR(500) = '',
    @edit17 NVARCHAR(500) = '',
    @edit18 NVARCHAR(500) = '',
    @edit19 NVARCHAR(500) = '',
    @edit20 NVARCHAR(500) = '',

    @dwdm_fgs VARCHAR(10) = '',
    @lx NVARCHAR(100) = '',
    @caption NVARCHAR(100) = '',

    @czydm VARCHAR(20) = '',
    @czyxm NVARCHAR(50) = '',
    @mkmc NVARCHAR(50) = '',

    @qxxssp VARCHAR(100) = '',
    @qxxsdw VARCHAR(8000) = '',
    @gsywbm VARCHAR(8000) = '',
    @yhrybm VARCHAR(8000) = '',

    @flag_sm NVARCHAR(500) = N'' OUTPUT
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @equipment_code VARCHAR(30);
    DECLARE @tag_keyword NVARCHAR(100);

    SET @flag_sm = N'';

    /* 设备编号优先取右键传入的args1 */
    SET @equipment_code =
        COALESCE
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    /* 页面第二个查询条件 */
    SET @tag_keyword =
        NULLIF(LTRIM(RTRIM(ISNULL(@edit2, N''))), N'');

    IF @equipment_code IS NULL
    BEGIN
        SET @flag_sm = N'没有获取到设备编号。';

        /* 上方空结果集 */
        SELECT
            CAST('' AS VARCHAR(20)) AS [标签编号],
            CAST(N'' AS NVARCHAR(100)) AS [标签名称]
        WHERE 1 = 0;

        /* 下方空结果集 */
        SELECT
            CAST('' AS VARCHAR(20)) AS [标签编号],
            CAST(N'' AS NVARCHAR(100)) AS [标签名称],
            CAST('' AS VARCHAR(19)) AS [选择时间]
        WHERE 1 = 0;

        RETURN;
    END;

    /*========================================
      结果集1：上方尚未选择的标签
    ========================================*/
    SELECT
        t.tag_code AS [标签编号],
        t.tag_name AS [标签名称]
    FROM dbo.t_equipment_tag t WITH(NOLOCK)

    LEFT JOIN dbo.t_equipment_tag_gx g WITH(NOLOCK)
        ON g.tag_code = t.tag_code
       AND g.equipment_code = @equipment_code
       AND g.czydm_gx = @czydm

    WHERE t.flag_enable = 1
      AND t.flag_zf = 0
      AND g.iid IS NULL

      AND
      (
          @tag_keyword IS NULL
          OR t.tag_code LIKE '%' + @tag_keyword + '%'
          OR t.tag_name LIKE N'%' + @tag_keyword + N'%'
      )

    ORDER BY t.sort_no, t.tag_code;

    /*========================================
      结果集2：下方已经选择的标签
    ========================================*/
    SELECT
        t.tag_code AS [标签编号],
        t.tag_name AS [标签名称],
        CONVERT(VARCHAR(19), g.time_gx, 120) AS [选择时间]
    FROM dbo.t_equipment_tag_gx g WITH(NOLOCK)

    INNER JOIN dbo.t_equipment_tag t WITH(NOLOCK)
        ON t.tag_code = g.tag_code

    WHERE g.equipment_code = @equipment_code
      AND g.czydm_gx = @czydm

    ORDER BY t.sort_no, t.tag_code;
END
GO
```

查询过程必须返回两个结果集：

```
第一个SELECT → 上方表格
第二个SELECT → 下方表格
```

```sql
        (
            NULLIF(LTRIM(RTRIM(ISNULL(@args1, N''))), N''),
            NULLIF(LTRIM(RTRIM(ISNULL(@edit1, N''))), N'')
        );

    SET @tag_keyword =
        NULLIF(LTRIM(RTRIM(ISNULL(@edit2, N''))), N'');

    /*========================================
      load：页面初始化
    ========================================*/
    IF @fs = 'load'
    BEGIN
        IF ISNULL(@equipment_code, '') = ''
        BEGIN
            SET @flag_sm = N'没有获取到设备编号。';
            RETURN;
        END;

        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_equipment
            WHERE equipment_code = @equipment_code
              AND flag_zf = 0
        )
        BEGIN
            SET @flag_sm = N'设备不存在或已经删除。';
            RETURN;
        END;

        /* 清除该用户、该设备的旧临时数据 */
        DELETE FROM dbo.t_equipment_tag_gx
        WHERE czydm_gx = @czydm
          AND equipment_code = @equipment_code;

        /* 将以前正式保存的标签重新加载到临时表 */
        INSERT INTO dbo.t_equipment_tag_gx
        (
            equipment_code,
            tag_code,
            czydm_gx,
            time_gx
        )
        SELECT DISTINCT
            r.equipment_code,
            r.tag_code,
            @czydm,
            @now
        FROM dbo.t_equipment_tag_rel r
        WHERE r.equipment_code = @equipment_code;

        RETURN;
    END;

    /*========================================
      dx：单选
    ========================================*/
    ELSE IF @fs = 'dx'
    BEGIN
        IF ISNULL(@equipment_code, '') = ''
        BEGIN
            SET @flag_sm = N'没有获取到设备编号。';
            RETURN;
        END;

        IF ISNULL(LTRIM(RTRIM(@pkey1)), '') = ''
        BEGIN
            SET @flag_sm = N'没有获取到标签编号。';
            RETURN;
        END;

        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_equipment_tag
            WHERE tag_code = @pkey1
              AND flag_enable = 1
              AND flag_zf = 0
        )
        BEGIN
            SET @flag_sm = N'标签不存在或已经停用。';
            RETURN;
        END;

        /* 临时表无唯一约束，所以代码中主动防重复 */
        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_equipment_tag_gx
            WHERE equipment_code = @equipment_code
              AND tag_code = @pkey1
              AND czydm_gx = @czydm
        )
        BEGIN
            INSERT INTO dbo.t_equipment_tag_gx
            (
                equipment_code,
                tag_code,
                czydm_gx,
                time_gx
            )
            VALUES
            (
                @equipment_code,
                @pkey1,
                @czydm,
                @now
            );
        END;

        RETURN;
    END;

    /*========================================
      qx：全选
      先清空当前用户、当前设备，再重新插入
    ========================================*/
    ELSE IF @fs = 'qx'
    BEGIN
        IF ISNULL(@equipment_code, '') = ''
        BEGIN
            SET @flag_sm = N'全选失败：没有获取到设备编号。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            DELETE FROM dbo.t_equipment_tag_gx
            WHERE czydm_gx = @czydm
              AND equipment_code = @equipment_code;

            /*
                全选必须使用t.tag_code，
                不能使用单选参数@pkey1。
            */
            INSERT INTO dbo.t_equipment_tag_gx
            (
                equipment_code,
                tag_code,
                czydm_gx,
                time_gx
            )
            SELECT DISTINCT
                @equipment_code,
                t.tag_code,
                @czydm,
                @now
            FROM dbo.t_equipment_tag t WITH(NOLOCK)
            WHERE t.flag_enable = 1
              AND t.flag_zf = 0
              AND ISNULL(LTRIM(RTRIM(t.tag_code)), '') <> ''

              AND
              (
                  @tag_keyword IS NULL
                  OR t.tag_code LIKE '%' + @tag_keyword + '%'
                  OR t.tag_name LIKE N'%' + @tag_keyword + N'%'
              );

            DECLARE @qx_count INT = @@ROWCOUNT;

            COMMIT TRAN;

            SET @flag_sm =
                N'全选成功，共选择'
                + CONVERT(NVARCHAR(20), @qx_count)
                + N'个标签。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'全选失败：'
                + ERROR_MESSAGE();

            RETURN;
        END CATCH;
    END;

    /*========================================
      ds：单删
    ========================================*/
    ELSE IF @fs = 'ds'
    BEGIN
        DELETE FROM dbo.t_equipment_tag_gx
        WHERE czydm_gx = @czydm
          AND equipment_code = @equipment_code
          AND tag_code = @pkey1;

        RETURN;
    END;

    /*========================================
      qs：全删
    ========================================*/
    ELSE IF @fs = 'qs'
    BEGIN
        DELETE FROM dbo.t_equipment_tag_gx
        WHERE czydm_gx = @czydm
          AND equipment_code = @equipment_code;

        SET @flag_sm = N'已清空当前设备的临时标签。';
        RETURN;
    END;

    /*========================================
      save：保存正式关系
    ========================================*/
    ELSE IF @fs = 'save'
    BEGIN
        IF ISNULL(@equipment_code, '') = ''
        BEGIN
            SET @flag_sm = N'保存失败：没有获取到设备编号。';
            RETURN;
        END;

        IF NOT EXISTS
        (
            SELECT 1
            FROM dbo.t_equipment
            WHERE equipment_code = @equipment_code
              AND flag_zf = 0
        )
        BEGIN
            SET @flag_sm = N'保存失败：设备不存在或已经删除。';
            RETURN;
        END;

        BEGIN TRY
            BEGIN TRAN;

            /* 删除原有正式关系 */
            DELETE FROM dbo.t_equipment_tag_rel
            WHERE equipment_code = @equipment_code;

            /* 保存当前临时选择 */
            INSERT INTO dbo.t_equipment_tag_rel
            (
                equipment_code,
                tag_code,
                czydm_dj,
                czyxm_dj,
                time_dj
            )
            SELECT DISTINCT
                g.equipment_code,
                g.tag_code,
                @czydm,
                ISNULL(NULLIF(@czyxm, N''), @czydm),
                @now
            FROM dbo.t_equipment_tag_gx g

            INNER JOIN dbo.t_equipment_tag t
                ON t.tag_code = g.tag_code

            WHERE g.czydm_gx = @czydm
              AND g.equipment_code = @equipment_code
              AND t.flag_enable = 1
              AND t.flag_zf = 0
              AND ISNULL(LTRIM(RTRIM(g.tag_code)), '') <> '';

            /* 保存后清理临时记录 */
            DELETE FROM dbo.t_equipment_tag_gx
            WHERE czydm_gx = @czydm
              AND equipment_code = @equipment_code;

            COMMIT TRAN;

            SET @flag_sm =
                N'设备【'
                + @equipment_code
                + N'】的标签保存成功。';

            RETURN;
        END TRY
        BEGIN CATCH
            IF @@TRANCOUNT > 0
                ROLLBACK TRAN;

            SET @flag_sm =
                N'保存失败：'
                + ERROR_MESSAGE()
                + N'；错误行：'
                + CONVERT(NVARCHAR(20), ERROR_LINE());

            RETURN;
        END CATCH;
    END;

    SET @flag_sm =
        N'未定义的上下选操作：'
        + ISNULL(@fs, N'NULL');
END
GO
```

# 11. 在设备台账中显示设备标签

在原设备主查询存储过程 `p_equipment_cx` 的主表查询中增加：

```sql
ISNULL
(
    (
        SELECT
            STRING_AGG
            (
                CONVERT(NVARCHAR(MAX), t.tag_name),
                N'、'
            )
            WITHIN GROUP
            (
                ORDER BY t.sort_no, t.tag_code
            )
        FROM dbo.t_equipment_tag_rel r

        INNER JOIN dbo.t_equipment_tag t
            ON t.tag_code = r.tag_code

        WHERE r.equipment_code = a.equipment_code
          AND t.flag_enable = 1
          AND t.flag_zf = 0
    ),
    N''
) AS [设备标签],
```

完整位置示例：

```sql
SELECT
    a.equipment_code AS [设备编号],
    a.equipment_name AS [设备名称],
    a.model_spec AS [型号规格],
    a.department_name AS [使用部门],
    a.keeper_name AS [负责人],

    CONVERT(VARCHAR(10), a.purchase_date, 23)
        AS [购置日期],

    a.equipment_status AS [设备状态],
    a.equipment_price AS [设备价格],

    ISNULL
    (
        (
            SELECT
                STRING_AGG
                (
                    CONVERT(NVARCHAR(MAX), t.tag_name),
                    N'、'
                )
                WITHIN GROUP
                (
                    ORDER BY t.sort_no, t.tag_code
                )
            FROM dbo.t_equipment_tag_rel r

              AND t.flag_enable = 1

    ) AS [设备标签],

    a.equipment_remark AS [设备备注]
```

不要直接普通连接关系表，否则一台设备有多个标签时，设备台账会出现多行重复设备。

# 13. 常见问题排查

## 13.1 报错“@args1不是过程参数”

原因：

```
公共路由传入了@args1
业务过程没有定义@args1
```

解决：

```
@args1 NVARCHAR(500) = ''
```

查询和操作两个过程都要定义。

------

## 13.2 报错“值不能为null，参数名key”

重点检查：

```
base_ggmkright.pkey
toformargxml中的value
设备查询结果列名
```

必须统一为：

```
设备编号
```

正确配置：

```
<Data><key lx="1" value="设备编号" /></Data>
```

------

## 13.3 点击全选没有反应

全选必须使用：

```
t.tag_code
```

不能使用：

```
@pkey1
```

因为全选时没有选中某一条记录，`@pkey1` 往往为空。

正确：

```
SELECT
    @equipment_code,
    t.tag_code,
    @czydm,
    GETDATE()
FROM dbo.t_equipment_tag t;
```

------

## 13.4 临时表中出现空标签编号

清理：

```
DELETE FROM TEST.dbo.t_equipment_tag_gx
WHERE ISNULL(LTRIM(RTRIM(tag_code)), '') = '';
```

并检查全选代码是否误用了：

```
@pkey1
```

------

## 13.5 单选重复插入

临时表没有唯一约束，因此单选分支必须保留：

```
IF NOT EXISTS
(
    SELECT 1
    FROM dbo.t_equipment_tag_gx
    WHERE equipment_code = @equipment_code
      AND tag_code = @pkey1
      AND czydm_gx = @czydm
)
```

------

## 13.6 查询只显示一张表

查询过程必须连续返回两个结果集：

```
SELECT上方数据
SELECT下方数据
```

即使没有设备编号，也需要返回两个空结果集。

------

## 13.7 保存后设备台账没有立即变化

保存完成后：

```
关闭上下选窗口
→ 回到设备台账
→ 再点击一次查询
```

设备标签列就会读取正式关系表中的最新数据。

# 14. 验收标准

功能完成后，应满足以下条件：

1. 设备台账右键能够看到“设备标签管理”。
2. 点击后能打开公共上下选窗口。
3. 当前设备编号能够正确传入 `@args1`。
4. 上方显示未选择标签。
5. 下方显示当前设备临时已选标签。
6. 单选后标签从上方进入下方。
7. 单删后标签从下方回到上方。
8. 全选后全部有效标签进入下方。
9. 全删后下方全部清空。
10. 保存后数据进入 `t_equipment_tag_rel`。
11. 再次打开同一设备时，原有标签自动加载到下方。
12. 设备台账主列表可以显示合并后的设备标签。

核心结构可以概括为：

```sql
右键lx=6负责打开上下选窗口
↓
toformargxml负责传设备编号
↓
路由表负责查找cx和cz业务过程
↓
查询过程返回上下两个结果集
↓
操作过程通过@fs完成上下移动和保存
↓
临时表负责页面过程
↓
```
